# Дом и порядок — сайт домашнего мастера

Одностраничный сайт сервиса бытовых услуг: электрика, сантехника, мебель. Продающая логика проста — срочная проблема, кейсы «до и после», прозрачные цены и кнопка «Вызвать мастера».

**Демо:** [shalim-andrej.github.io/dom-i-poryadok](https://shalim-andrej.github.io/dom-i-poryadok/)

## О проекте

Концепт-сайт вымышленного сервиса «Дом и порядок» — портфолио-кейс для ниши, где клиент покупает не красоту, а решение проблемы. Оффер «приезд за 60 минут» стоит в заголовке браузера и первом экране. Доверие собирают три блока подряд: реальные кейсы «до и после», честный прайс без «цена по запросу» и отзывы.

Вёрстка написана с нуля, без конструкторов и фреймворков: чистые HTML, CSS и JavaScript.

## Структура страницы

| Блок | Задача |
|---|---|
| Первый экран | оффер «приезд за 60 минут» и кнопка вызова |
| Услуги | электрика, сантехника, мебель |
| До и после | фото-кейсы выполненных работ |
| Цены | прозрачный прайс без скрытых доплат |
| Отзывы | социальные доказательства |
| Вызвать мастера | форма заявки |

## Технологии

- **HTML5** — семантическая разметка, доступная для поисковиков и скринридеров
- **CSS3** — Flexbox и Grid, адаптив от смартфона до широкого монитора
- **JavaScript (vanilla)** — вся интерактивность без внешних библиотек
- **Форма вызова мастера** — короткая, под срочную заявку
- **SEO-база** — `<title>` с перечнем услуг и оффером, `meta description`

## Запуск локально

```bash
git clone https://github.com/shalim-andrej/dom-i-poryadok.git
cd dom-i-poryadok
```

Откройте `index.html` в браузере — сборка и зависимости не нужны.
